Drop .ttf / .otf / .ttc font files here.

Fukidashi uses fonts from this folder before any system font. If you put
several fonts here, choose one by name in the extension popup (the "font"
option is matched against the file name, case-insensitive, without extension);
otherwise the first file in alphabetical order is used.

For Japanese / Chinese / Korean target languages a font is only used if it
actually contains the needed glyphs; otherwise a CJK system font is chosen.
